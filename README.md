 Fitur Utama

🔍 Pengenalan Wajah Presisi Tinggi (Face ID)

Menggunakan model Neural Network SSD MobileNetv1 via face-api.js untuk mengidentifikasi dan memverifikasi wajah secara real-time.

✍️ Tanda Tangan Digital (Canvas ID)

Dukungan kanvas tanda tangan interaktif berbasis sentuhan (touchscreen) maupun kursor mouse untuk validasi legalitas presensi.

📊 Sinkronisasi Otomatis Google Sheets

Data kehadiran yang berhasil dipindai dikirim secara real-time ke serverless Google Apps Script dan tersimpan di Google Sheets.

📄 Ekspor Laporan PDF Otomatis

Fitur cetak rekapitulasi presensi harian dengan Kop Surat resmi Proyek Nusa Putra lengkap dengan visualisasi tanda tangan pekerja.

💾 Local Storage Encrypted Database

Menyimpan vektor deskriptor wajah (128-float array) dan gambar tanda tangan langsung di peramban tanpa memerlukan database SQL eksternal.
